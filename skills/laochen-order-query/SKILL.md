# 订单状态查询助手

## 功能说明

用户通过订单号、手机号或客户名称，快速查询订单的当前状态、配送进度和历史订单记录。

## 查询范围

- 订单状态：待确认 / 采购中 / 备货完成 / 配送中 / 已送达 / 异常
- 订单详情：商品明细、数量、金额、下单时间
- 配送信息：配送进度、签收状态、异常记录

## 使用示例

- 用户："查一下订单 S00088 到哪了"
- 用户："我今天有什么订单"
- 用户："帮我看看上周的订单"

## 说明

本技能由商家授权接入订单系统数据，仅返回该客户自己的订单信息，不涉及其他客户数据。
