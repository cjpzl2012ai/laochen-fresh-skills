# 老陈鲜配·经营日报助手

## 解决什么问题

生鲜蔬菜批发老板每天最头疼的事：货卖了多少、赚了多少、哪些菜亏了、明天该进多少货。
本工具把散落在订单、采购单里的数据，自动汇总成一份**看得懂的经营日报**。

## 日报内容

- **今日销售额 / 订单数 / 客户数** — 一眼看清生意规模
- **毛利分析** — 每个菜品的进价与售价毛利，找出赚钱的和亏钱的
- **库存预警** — 哪些菜库存不足需要补货、哪些积压容易坏
- **采购建议** — 根据销量预测明日采购量，减少损耗
- **异常提醒** — 缺价商品、负库存、异常订单自动标记

## 使用示例

- 用户："生成今日经营日报"
- 用户："昨天生意怎么样"
- 用户："给我看看今天的销售情况"

## 说明

本技能由商家授权接入经营数据，仅返回该商家自己的经营数据，不涉及其他客户数据。
